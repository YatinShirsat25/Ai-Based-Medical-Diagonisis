## 📋 Quick Reference

### Login System
- **File**: app_flask.py (lines with login_user function)
- **Database**: medical_ai.db (users table)
- **Security**: Bcrypt password hashing
- **Session**: Flask session management

### Data Storage
- **Database**: SQLite (medical_ai.db)
- **Tables**: users, patient_records
- **Models**: Pickle files in models/ folder
- **Quiz Data**: CSV file (disease_mcq_dataset_500.csv)

### Key Features
- ✅ User authentication (signup/login)
- ✅ 3 disease diagnosis models
- ✅ 500 medical quiz questions
- ✅ Patient record management
- ✅ Leaderboard system
- ✅ Progress tracking

### Security Features
- ✅ Bcrypt password hashing
- ✅ Parameterized queries (SQL injection proof)
- ✅ Session-based authentication
- ✅ Input validation
- ✅ Generic error messages
- ✅ Login required decorator

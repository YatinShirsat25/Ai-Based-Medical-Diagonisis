## 🎯 What This Project Does

### 🏥 Disease Diagnosis
Three AI-powered risk assessments:
- **Diabetes**: 17-parameter evaluation
- **Blood Pressure**: 13+ parameter assessment
- **Lung Cancer**: 13 symptom evaluation

### 📚 Medical Training
Interactive quiz system:
- 500 medical questions
- 3 difficulty levels
- Immediate feedback
- Progress tracking
- Leaderboard

### 💾 Patient Records
- Save all diagnosis results
- View complete history
- Track assessments over time

## 🆘 Troubleshooting

### Port Already in Use?
Edit `app_flask.py` and change port 5000 to another number (e.g., 5001)

### Database Issues?
Delete `medical_ai.db` and restart the app to reset

### Model Loading Warnings?
These are non-critical version compatibility warnings. The app works fine.
